# QAQC Hub

GYOW QA/QC browser tools, published at https://gyow-qaqc.github.io/

- `field-reports/` Field Reports app (built from the development sources; do not edit here by hand)

The tools run in the browser. No report data is stored in this repository: reports live in the
OKO-QAQC SharePoint library and on the devices that work on them.
