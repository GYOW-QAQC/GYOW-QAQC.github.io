Quick reference: key concepts

Coaching cheat-sheet: quick topics to jog memory before an inspection, not a full restatement of the standard.

AQL: Acceptable Quality Limit
  • The quality level treated as satisfactory as a long-run process average, not a guarantee for any single lot.
  • Lower AQL = tighter requirement → smaller Ac for the same sample size.
  • Set per characteristic before inspection starts, major defects usually get a tighter AQL than minor/cosmetic ones.
  • Comes from the ITR / inspection plan, never picked on the fly by the inspector.
General Inspection Levels (I, II, III)
  • Control how much discriminating power the plan has, for the same lot size and AQL.
  • II is the default, use it unless the plan says otherwise.
  • I = smaller sample, less discrimination, lower-stakes, cost/time-sensitive checks.
  • III = larger sample, more discrimination, higher-consequence characteristics.
Special Inspection Levels (S-1 to S-4)
  • Use only when sampling itself is destructive, slow, or expensive.
  • Trade discrimination for a much smaller sample, higher risk of the wrong call.
  • S-1 = smallest sample of the four; S-4 = largest of the four (still smaller than General I in most lot ranges).
  • Only applies when the inspection plan explicitly calls for it.
Switching: Normal ⇄ Tightened ⇄ Reduced
  • Start every new supplier/characteristic on Normal.
  • Tightened kicks in when recent lots show quality slipping, same sample size as Normal, stricter Ac/Re.
  • Reduced only applies after sustained good quality, stable production, and sign-off from the responsible authority, smaller sample size.
  • A rejected lot under Reduced sends you straight back to Normal.

Table 1: lot size → sample character

Cross the lot size range with the inspection level. General II is the everyday default; special levels (S-1 to S-4) cut the sample size drastically and only apply when the inspection plan says so explicitly.

  1. Find the row. Locate, in the "Lot or batch size" column, the range your lot size (N) falls into.
  2. Pick the column. Use General II, unless the inspection plan states otherwise.
  3. Read the letter. The row × column intersection is the sample character, a letter from A to S.

Example: a lot of 1,200 pieces, General II → falls in the "501 to 1,200" range → letter J.

The letter on its own says nothing about quality, it's just an intermediate code. It exists so it can be plugged into the Master Table below, which converts it into "how many pieces to sample" and "how many nonconformities accept/reject the lot." A letter further down the alphabet = bigger lot = bigger sample; never skip straight to an AQL without passing through this table first.

Ac = acceptance number (nonconformities up to this value → accept the lot). Re = rejection number. Arrows (↓ ↑) mean the real Ac/Re pair sits on a neighboring row, the tool above already resolves this; use the tables only for visual cross-check.

About the data: Table 1 uses the standard values published in ISO 2859‑1:1999 / ANSI-ASQ Z1.4. The Master Tables were reconstructed from the PDF Single-sampling-plans-for-normal-inspection-ISO-2859-1-Master-Table.pdf (Regulations and Standards), combining the letters/sample sizes extracted from that document with the standard AQL-column alignment, and checked against known reference points (e.g. letter H/AQL 1.0% → Ac 1/Re 2; letter K/AQL 1.5% → Ac 5/Re 6; letter N/AQL 1.0% → Ac 10/Re 11). For AQLs above roughly 25% (rarely used on site) and for the extreme letters A to C and R to S, always confirm against the original PDF before a lot-disposition decision. Note also: ANSI/ASQ Z1.4's Reduced-inspection plans historically keep a gap between Ac and Re (accept but revert to Normal in between); ISO 2859-1:1999 (the basis of this tool) removed that gap. Normal and Tightened match between the two standards.
